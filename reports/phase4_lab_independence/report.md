# 医学检验常数：独立核验路径与差异审计

- 版本 `lab-independence-1.0.0`，生成时间 2026-10-26T18:11:35Z
- 生成器与验证器共享 `clinforge/hpo_knowledge.REFERENCE_INTERVALS`；本审计新增 `clinforge/lab_standards.py` 作为**第二条路径**，不修改任何金标。

## 1. 独立路径怎么来的

| 量 | 项目共享表 | 独立路径 | 相对差 |
| --- | --- | --- | --- |
| ALT 换算因子 | 1.0 | 1.0 | 0.00e+00 |
| AST 换算因子 | 1.0 | 1.0 | 0.00e+00 |
| GLUCOSE 换算因子 | 0.05550622 | 0.05550745 | 2.22e-05 |
| HGB 换算因子 | 10.0 | 10.0 | 0.00e+00 |

独立路径的换算因子由分子式与 CIAAW 标准原子量推导：

- 葡萄糖 C6H12O6，摩尔质量 180.156 g/mol；
- 肌酐 C4H7N3O，摩尔质量 113.120 g/mol；
- 血红蛋白 g/dL → g/L 是 SI 词头定义（×10），不需要摩尔质量；
- ALT/AST 是催化活性浓度（U/L），不做质量换算。

参考区间（演示值，非临床标准）：

| 分析物 | 项目表 | 独立表 | 是否一致 |
| --- | --- | --- | --- |
| ALT | [7.0, 40.0] | [7.0, 40.0] | 是 |
| AST | [8.0, 40.0] | [8.0, 40.0] | 是 |
| GLUCOSE | [3.9, 6.1] | [3.9, 6.1] | 是 |
| HGB | [115.0, 175.0] | [115.0, 175.0] | 是 |

> 区间状态：**demo values for pipeline testing; not a clinical reference standard**。本审计只能证明"两份实现一致"，不能证明区间本身在临床上正确。

## 2. 语料重算（1,277 个检验值）

| 指标 | 数值 |
| --- | --- |
| 检验值总数 | 1,277 |
| 可解析并重算 | 1,277 |
| 换算不一致 | 0 |
| 方向（高/低/正常）不一致 | 0 |
| 最大绝对偏差 | 0.01 |

按分析物：`{"HGB": 346, "GLUCOSE": 488, "ALT": 344, "AST": 99}`；按单位：`{"g/L": 244, "mmol/L": 396, "U/L": 443, "g/dL": 102, "mg/dL": 92}`。

结论：独立路径下 1,277 个检验值全部复算一致，方向判定也全部一致。这不是"金标正确"的证明，只说明共享表的换算没有被实现错误污染。

## 3. 循环验证演示（故意注入错误）

在内存中把共享表改成：葡萄糖换算因子 18.016→20.0、血红蛋白 10.0→12.0、血糖上限 6.1→4.5、血红蛋白下限 115→160，生成 300 条病例（seed 424242），然后分别用两种路径验证同一条病例。

| 验证路径 | 检验值 | 换算不一致 | 方向不一致 |
| --- | --- | --- | --- |
| 共享表（生成与验证用同一张错表） | 159 | 0 | 0 |
| 独立路径（生成用错表，验证用推导值） | 159 | 26 | 10 |

共享表那一臂按构造必然通过；独立路径检出了注入的换算与区间错误，说明第二条路径恰好对循环验证会掩盖的那类错误敏感。

注入的错误没有被写回任何真实产物；实验结束后共享表已恢复，`data/phase3_synth/gen/notes.jsonl` 未被修改。

## 4. 能证明与不能证明

- 能证明：换算与演示区间由两套不同输入分别实现；1,277 个检验值在独立路径下复算一致；第二条路径能检出共享表看不见的注入错误。
- 不能证明：演示区间在临床上正确。真实参考区间取决于方法、分析仪与人群，本机没有实验室标准或室间质评数据。
