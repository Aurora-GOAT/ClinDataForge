## 1. 为什么要重建评测集

旧资料中的 730 条合成病历与 60 条压力集存在两个不能接受的问题：

1. 标签由同一个程序生成，检测器与生成器共享模板假设，模板内 F1=1.0 属于自证；跨模板压力集上 PHI 召回只有 55.56%，说明旧分数不能外推。
2. 60 条压力集中"完整覆盖已标注实体"的记录只有 10/60，不能当作独立验收集。

因此本阶段**不再让旧集承担独立测试集角色**，只保留为历史诊断资料。新集合必须满足：来源可查、许可明确、来源与检测器的开发过程独立、划分无泄漏、哈希可复现。

## 4. 划分与泄漏控制

划分单位是**近重复连通分量**。两份文档满足以下任一条件即并入同一分量，分量不得跨划分：

1. PHI 与临床段遮蔽后的骨架完全相同；
2. 骨架 5-gram Jaccard ≥ 0.50；
3. 另一套掩码（保留数字，仅留字母数字与汉字）6-gram Jaccard ≥ 0.50；
4. 同一中文模板族。

相似对检索使用前缀过滤（prefix filtering）的精确 Jaccard 连接，理论上不留假阴性，并由单元测试 `test_jaccard_pairs_matches_brute_force` 与暴力枚举对拍验证。

### 审计发现与修正（两轮）

| 轮次 | 发现问题 | 处理 |
| --- | --- | --- |
| 1 | 34 个中文模板族跨划分（同一族的正常样本与硬负样本被分到不同集合） | 把"中文模板族"直接并入连通分量 |
| 1 | 359 对跨划分文档 6-gram Jaccard ≥ 0.50 | 收紧阈值 0.70 → 0.50，并引入第二种掩码的第二路连接 |
| 2 | 仍余 9 对跨划分（构建器的 shingle 函数会剥离 `\|` 标签分隔符，与审计口径不一致，等于静默放宽了检查） | 新增 `shingle_set()` 与审计口径完全一致，并加回归测试 `test_builder_and_audit_masks_agree` |
| 2 | 40 条中文硬负样本只差一个数字，互相构成完全近重复，把全部 320 条中文锁进单一分量，导致 dev/test 无中文 | 重写为 40 条各自不同的无 PHI 临床记录 |

最终审计结论 **PASS**：相同文本跨划分 0 对、独立掩码碰撞跨划分 0 对、模板族跨划分 0 个、跨划分 Jaccard ≥ 0.50 文档对 0 对。
